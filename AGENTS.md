# AGENTS.md — Руководство для агентов

## 1. О проекте
Универсальное детерминированное ядро для автономных ИИ-агентов: статическая защита кодовой базы, изоляция ролей исполнителя и критика, управление контекстом и контроль целостности артефактов.
Это рабочий шаблон: правила ниже коротко объясняют, как здесь работать и что считается готовым.

## 2. Структура репозитория
- `core/` — модули ядра; `tests/` — тесты;
- `plans/` — план текущей задачи; `HANDOFF.md` — мост между сессиями;
- `schemas/` — контракты; `docs/` — архив документов и внешний аудит.

## 3. Запуск и проверка
- Все тесты: `python -m unittest discover tests`
- Один модуль: `python -m unittest tests/test_<name>.py`

Работа готова, только когда тесты зелёные (`exit_code: 0`). Если падают — покажи вывод и своё объяснение, ошибки не глотай.

## 4. Как работаем
1. Сначала короткий план (3–7 пунктов) — и дождись моего «ок».
2. Одна задача за раз. Заметил посторонний баг — запиши в конец ответа, не чини без спроса.
3. Не переписывай модуль целиком — меняй точечно.
4. Задача неясна — спроси. Не додумывай.
5. После правки файла перечитай изменённые строки, потом запускай тесты.

## 5. Чего не делать (и почему)
- Не меняй `tests/`, `schemas/`, `.agents/hooks.json` без моей просьбы — это моя проверка твоей работы.
- Не выполняй `git push`, `git reset --hard`, удаление папок — это делаю я сам после ревью.
- Не хардкодь пути своей машины (`G:\...`) — проект должен запускаться везде.
- Не глотай исключения молча и не подставляй выдуманные значения, если инструмент недоступен, — скажи честно.
- Никаких сетевых вызовов без явного разрешения в задаче.

## 6. Стиль кода
- Понятные имена: целое слово лучше загадочного сокращения.
- Маленькие функции, ранний выход вместо глубокой вложенности.
- Типы в сигнатурах; `None` обрабатывай явно.
- 1 коммит = 1 намерение; сообщение отвечает «что и почему».

## 7. Definition of Done и отчёт
1. Изменения только в файлах из согласованного списка.
2. `python -m unittest discover tests` — `exit_code: 0`.
3. Изменённые строки перечитаны, синтаксис цел.
4. Отчёт: что сделал (2–5 строк), какие файлы, вывод проверки, что под вопросом — и строка состояния в `HANDOFF.md`.
