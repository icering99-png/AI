# AGENTS.md — Руководство для ИИ-агентов

> Краткое операционное руководство и точка входа для ИИ-ассистентов в этом репозитории.

---

## 1. О проекте
Этот репозиторий содержит **Эталон ИИ** — надежное ядро оркестрации локальных ИИ-агентов, управляемое тестами.
Система включает детерминированные барьеры защиты, восстановление после сбоев, контекстную память на SQLite FTS5 и инструменты безопасного выполнения команд.

---
