# DevOps Quest — Интерактивный тренажер: Git, CI/CD, Тестирование

Локальное интерактивное веб-приложение для экстренной подготовки инженера к собеседованию и безопасной работе в проекте чат-бота МТС под кураторством Андрея.

---

## 🚀 Как запустить на Windows

Приложение работает **100% автономно и оффлайн**, без внешних серверов, Docker и API-ключей.

### Способ 1: Открытие напрямую в браузере (Самый быстрый)
1. Откройте проводник Windows по адресу:
   `g:\AI\Программка\Antigravity\Эталон ИИ\devops_quest\`
2. Дважды кликните на файл `index.html`.
3. Приложение откроется в вашем браузере (Chrome / Edge / Firefox).

### Способ 2: Запуск через локальный HTTP-сервер Python
В терминале Antigravity / PowerShell:
```powershell
cd "g:\AI\Программка\Antigravity\Эталон ИИ\devops_quest"
python -m http.server 8080
```
После этого откройте ссылку: [http://localhost:8080](http://localhost:8080)

## 🧭 Структура и возможности тренажера

1. **📚 Учебные модули (12 разделов):**
   * Модуль 1: Основы Git, Blob/Tree/Commit/Tag, три состояния (Working, Staging, Repository), `.gitignore`;
   * Модуль 2: Ветки, Fast-Forward, Three-Way Merge, Rebase, Reset vs Revert, `git reflog`;
   * Модуль 3: Разрешение Merge-конфликтов (разметка `<<<<<<< HEAD`, пошаговый алгоритм);
   * Модуль 4: Pull Request / Merge Request, Code Review, коммуникация с Андреем;
   * Модуль 5: Пирамида тестирования (Unit, Integration, E2E), позитивные и негативные проверки;
   * Модуль 6: Автоматизация на Python: Pytest, паттерн AAA, фикстуры, параметризация;
   * Модуль 7: E2E тестирование с Playwright: Auto-waiting vs sleep, селекторы;
   * Модуль 8: CI/CD: что происходит после `git push`, разбор `.github/workflows/ci.yml`, Artifacts vs Cache;
   * Модуль 9: Защита веток (Branch Protection), релизы, SemVer, безопасный Rollback;
   * Модуль 10: Разбор типовых аварий: «в CI падает, локально работает», Detached HEAD, Rejected push;
   * Модуль 11: Специфика проекта МТС: роли Андрея и Данила, Claude Code vs Claude API, защита ПДн;
   * Модуль 12: Как устроены большие компании: письменная культура и RFC, ADR, DORA-метрики, SLO и бюджет ошибок, on-call, техдолг и Definition of Done, встречи, вопросы и работа с легаси.

2. **💻 Интерактивный Git-терминал с графом:**
   * Поддерживает реальные команды: `status`, `add`, `commit`, `switch`, `branch`, `diff`, `log`, `push`, `pull`, `reflog`.
   * **Сторож Андрея:** автоматически блокирует опасные стоп-слова (`--force`, `reset --hard`, `clean`, `rebase`, `branch -D`, `push origin main`).
   * Визуальный граф коммитов и раздельное отображение Working Tree и Staging Area.

3. **🔀 Pull Request и тренажер конфликтов:**
   * Просмотр Diff с подсветкой синтаксиса;
   * Симуляция Merge-конфликта в `answers.py`;
   * Интерактивные кнопки разрешения: *Accept Incoming*, *Accept Current*, *Accept Both*, *Abort*;
   * Одобрение Андреем (Approved) и вливание в `main`.

4. **⚙️ CI/CD Пайплайн:**
   * Интерактивный запуск стадий: Lint -> Pytest -> Playwright E2E -> Staging Deploy;
   * Симуляция падения теста маскировки ПДн МТС с просмотром логов Runner;
   * Кнопка исправления ошибки и перезапуска.

5. **🎯 Экзамен / Собеседование:**
   * Режим «⚡ Экстренный интенсив» — топ каверзных вопросов на собеседовании;
   * Режим «🎓 Полный экзамен без подсказок» — без ранних ответов, с начислением XP и зачетом компетенций;
   * Подробный разбор каждого ответа («Почему это верно», «Разбор альтернатив», «Заметка для собеседования»).

6. **📖 Памятка Андрея и Справочник:**
   * Главное правило: «В main не работаем, только в своей ветке danil/...»;
   * 4 ежедневных шага;
   * Интерактивный поиск по командам.

## 💾 Сохранение прогресса
* Все данные (XP, уровень, изученные темы, шкала готовности к собеседованию) сохраняются в браузере (`localStorage`).
* Доступны кнопки **📥 Экспорт** и **📤 Импорт** прогресса в формате JSON.
