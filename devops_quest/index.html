      🌿 Памятка Андрея для Данила: «Git без паники»

      ⭐ Главное правило

      Никогда не работаем в main! Работаем строго в своей ветке danil/... (например: danil/tariffs). В main код переносит только Андрей через Pull Request.

      ⛔ Стоп-слова для ИИ (Gemini)

      Если Gemini предлагает выполнить: --force, -f, reset --hard, clean, rebase, branch -D, push origin main или удалить .git — жми REJECT!

      🔑 Безопасность и секреты

      Никогда не коммитить: пароли, API-ключи, .env, персональные данные (номера телефонов, ФИО клиентов) и выгрузки МТС. Проверяй список файлов в панели Git перед каждым коммитом.

      🔄 4 шага каждый день

      1. Забрать: git pull / Sync
      2. Работать: в ветке danil/...
      3. Сохранить: git commit -m "Понятный текст"
      4. Отправить: git push и открыть PR
      💡 Ленивый режим: дважды кликни daily.bat в папке игры — он сделает все 4 шага сам, включая сохранение progress.json.
